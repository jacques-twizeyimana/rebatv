# rebaTV · TV app (LG webOS + Hisense VIDAA)

The rebaTV app for smart TVs, built for the remote: D-pad, OK, BACK, CH +/−, number keys and the Magic Remote pointer. One codebase, two ways to ship:

| Platform | How it ships | Loads from | Talks to |
| --- | --- | --- | --- |
| **LG webOS 4+** (2018+, Chromium 53+) | Packaged `.ipk` (LG Content Store / Developer Mode) | `file://` inside the package | `VITE_API_BASE`, default `https://rebatv.bugufi.link` |
| **Hisense VIDAA U4+** | Hosted web app: VIDAA registers a URL | `https://rebatv.bugufi.link/tv/index.html` (deployed with the web app) | Same origin |

Channels, numbering, featured picks and heroes all come from `rebatv-web`, so nothing is hard-coded here:

- `GET /api/v1/lineup/{cc}`: the market's lineup (see `../rebatv-web/src/lib/api.ts`). The last copy is cached in `localStorage`, so the app opens instantly and survives short outages.
- `GET /api/v1/locate`: picks a market on first launch from the visitor's country.
- `/hls/{slug}/playlist.m3u8`: the playlist proxy. hls.js plays through it, and the TV's native HLS player with the broadcaster's URL is the fallback (the same strategy as the web player).
- `/_next/image?…`: channel logos, resized by the web app.

## Develop

```bash
cd rebatv-web && pnpm dev      # API + proxy on :3000 (needs its database, see its README)
cd rebatv-webos && pnpm install && pnpm dev   # http://localhost:5173, proxies /api /hls /_next/image to :3000
```

Use a 1920×1080 window. Arrow keys move, Enter is OK, Escape or Backspace is BACK, PageUp/PageDown are CH +/−, and digits tune a channel number. `pnpm test` runs the unit tests (keys, number entry, API base, spatial navigation).

## Build

```bash
pnpm build     # typecheck → dist/ → es-check (fails if the bundle isn't ES2016 / Chromium 53 safe)
pnpm preview   # serve dist/ on :4173 (same proxies as dev)
```

The output is deliberately one classic script plus one stylesheet, all with relative URLs:

- `file://` refuses `<script type="module">` and anything marked `crossorigin`, so a loader that fetches chunks (e.g. `@vitejs/plugin-legacy`'s SystemJS) breaks in the packaged app.
- Every module, `node_modules` included, goes through Babel `preset-env` for Chrome 53, with core-js polyfills added per use (`vite.config.ts`).
- The CSS avoids grid, flex `gap`, `aspect-ratio`, `:has()`, `:focus-visible`, nesting and `position: sticky`. Spacing uses margins, and rows/lists slide with transforms instead of scrolling (`src/nav.ts`).

## LG webOS

### Run on your TV (Developer Mode)

1. On the TV, install **Developer Mode** from the LG Content Store and sign in with an [LG developer account](https://webostv.developer.lge.com/). Turn on *Dev Mode Status* and *Key Server*, then restart. Dev Mode expires after 50 hours unless you extend it in the app.
2. On your computer (the CLI is installed with this project's devDependencies, so run these through `pnpm exec`):
   ```bash
   pnpm exec ares-setup-device          # add: name "tv", the TV's IP, port 9922, user "prisoner"
   pnpm exec ares-novacom --device tv --getkey   # enter the passphrase shown in the Developer Mode app
   ```
3. Build, install and launch:
   ```bash
   pnpm package                          # → out/com.rebatv.tv_<version>_all.ipk
   TV_DEVICE=tv pnpm install:tv
   TV_DEVICE=tv pnpm launch:tv
   pnpm exec ares-inspect --device tv --app com.rebatv.tv --open   # Chrome DevTools for the app
   ```

You can also use the [webOS TV Simulator](https://webostv.developer.lge.com/develop/tools/simulator-introduction): `pnpm exec ares-launch --simulator <version> dist` after `pnpm package`.

### Package details

- `webos/appinfo.json`:
  - `id: com.rebatv.tv`. This is permanent once the app is published.
  - `resolution: 1920x1080`.
  - `disableBackHistoryAPI: true`, so BACK (`461`) reaches the app. BACK on Home opens an "Exit rebaTV?" dialog, as LG's review requires, and **Exit** calls `window.close()` (or `webOS.platformBack()` when `webOSTV.js` is loaded).
  - `requiredACG: []`, because the app uses no Luna APIs.
  - The version is copied from `package.json` at packaging time. Bump it there for every store release.
- The launcher icons (80 and 130 px) and the 1920×1080 splash in `webos/` are generated by `pnpm icons` (`scripts/make-icons.mjs`) from the brand mark.
- When the app goes to the background the stream is stopped, and it restarts at the live edge on return (LG guideline). The lineup is refreshed if it is older than 30 minutes.
- Publishing: upload the `.ipk` in the [LG Seller Lounge](https://seller.lgappstv.com/) together with the store listing (screenshots, description, age rating).

## Hisense VIDAA

VIDAA apps are hosted, so there is no package. `deploy/deploy.sh` (repo root) builds this project on every deploy and copies `dist/` into the web release's `public/tv/`. Register **`https://rebatv.bugufi.link/tv/index.html`** in the VIDAA partner portal. To try it before registering, open the URL in the TV's browser.

On VIDAA, BACK arrives as Backspace (`8`). That is why Search's Backspace-deletes-a-letter shortcut is turned off there (Search has a Delete key).

## Remote keys

| Key | `key` / `keyCode` | Home & lists | Player |
| --- | --- | --- | --- |
| Arrows | `Arrow*` / 37–40 | Move focus | ▲▼ zap, ◀▶ move between controls |
| OK | `Enter` / 13 | Select | Select (first press only shows the controls) |
| BACK | 461 (webOS), 8 (VIDAA), `Escape`, 10009 (Tizen) | Back; on Home, exit dialog | Back to the list |
| CH + / CH − | `ChannelUp/Down`, `PageUp/Down`, 427/428 | — | Zap |
| 0–9 | 48–57, 96–105 | Type a channel number, tunes after 1.5 s | Same |
| ▶ ⏸ ■ | 415, 19, 463/179, 413 | — | Play (back to live), pause, stop |

The mapping lives in `src/keys.ts` and is tested in `tests/keys.test.ts`.

## Code map

- `src/App.tsx`: screen stack (Home → Search / Settings → Player). Covered screens stay mounted, so focus and scroll positions survive. It also holds the one keydown listener, number entry and the exit dialog.
- `src/nav.ts`: spatial navigation (a port of the web's `SpatialNav`) and sliding rows/lists. Screens claim keys first through `src/keybus.ts`.
- `src/screens/Player.tsx`: a port of the web player (hls.js light, then native fallback, bandwidth seeding, muted-autoplay → unmute, auto-hiding overlay).
- `src/api.ts`, `src/types.ts`: the v1 API client and types. Keep the types in sync with `rebatv-web/src/lib/api.ts`.
